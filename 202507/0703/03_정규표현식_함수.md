# 🔍 파이썬 정규표현식 함수 정리 (re 모듈)

파이썬에서 정규표현식은 `re` 모듈을 통해 사용할 수 있습니다.  
아래는 주요 함수들과 설명을 정리한 문서입니다.



## 1️⃣ re.match()

```python
re.match(pattern, string)
```

- **설명**: 문자열의 **시작 부분**부터 패턴이 일치하는지 검사합니다.
- **특징**: 반드시 문자열의 **맨 앞**부터 매치되어야 합니다.
- **반환**: 매치 객체 (match object) / 실패 시 None

📌 예시:
```python
import re
re.match("abc", "abcdef")  # ✅ 매치됨
re.match("def", "abcdef")  # ❌ 매치 안됨
```



## 2️⃣ re.search()

```python
re.search(pattern, string)
```

- **설명**: 문자열 전체에서 패턴이 **처음으로 등장하는 곳**을 검색합니다.
- **반환**: 매치 객체 / 실패 시 None

📌 예시:
```python
re.search("abc", "123 abc 456")  # ✅ 매치됨
```



## 3️⃣ re.findall()

```python
re.findall(pattern, string)
```

- **설명**: 문자열 전체에서 **패턴과 일치하는 모든 문자열**을 **리스트(list)** 로 반환합니다.
- **반환**: 리스트

📌 예시:
```python
re.findall(r"\d+", "abc 123 def 456")  
# 출력: ['123', '456']
```



## 4️⃣ re.finditer()

```python
re.finditer(pattern, string)
```

- **설명**: 문자열 전체에서 **패턴과 일치하는 모든 결과**를 **이터레이터(iterator)** 로 반환합니다.
- **반환**: match 객체 반복자

📌 예시:
```python
for m in re.finditer(r"\d+", "abc 123 def 456"):
    print(m.group())
```



## 5️⃣ re.sub()

```python
re.sub(pattern, repl, string, count=0, flags=0)
```

- **설명**: 문자열에서 **패턴과 일치하는 모든 부분을 교체**합니다.
- **repl**: 대체할 문자열
- **count**: 교체할 횟수 (기본은 전체)

📌 예시:
```python
re.sub(r"\d+", "#", "abc 123 def 456")
# 출력: 'abc # def #'
```



## 6️⃣ re.compile()

```python
re.compile(pattern, flags=0)
```

- **설명**: 정규식을 미리 컴파일해서 `패턴 객체`를 생성합니다.
- **장점**: 여러 번 사용할 경우 성능 향상

📌 예시:
```python
pattern = re.compile(r"\d+")
pattern.findall("123 abc 456")
```



## ✅ 예시 모음

```python
re.findall(r"[a-z]+", "abc123XYZ")  # ['abc']
re.findall(r"\d{2,3}", "My phone: 010-1234-5678")  # ['010', '123', '567']
re.sub(r"[aeiou]", "*", "hello world")  # 'h*ll* w*rld'
```
