## 🟢 `Datatime` Module

- date Class – date 클래스는 날짜에 대한 정보를 다룹니다. 연도, 월, 일
- time Class – time 클래스는 시간에 대한 정보를 다룹니다.
- datetime Class – datetime 클래스는 날짜와 시간에 대한 모든 정보를 다룹니다.
- timedelta Class – timedelta 클래스는 두 날짜와 시간 사이의 차이를 다룹니다 



```python
import datetime

today = datetime.datetime.now()   # 현재 날짜와 시간정보를 준다.
print(today)

# python 'dir' function / 기본적으로 내부구조를 보여준다.
print(dir(today))

# 날짜와 날짜의 연상을 수행하려면 날짜를 date클래스나 datetime클래스로 변환해야 연산이 가능하다.
dt = datetime.date(2025, 7, 31)
print(dt)
```

## 🟢 timestamp로 부터 날짜 정보 얻기

 timestamp는 유닉스/리눅스 계열에서 사용하는 시간을 나타내는 정수입니다.  
 1970년1월1일 0시0분0초부터 몇초가 지났는 지를 나타내는 정수값입니다.  
이 타임스탬프는 지구자전축의 움직임을 고려하는 윤초(Leap Second)까지 반영하여 아주 엄격하게 정의한 숫자가 아니라, 단순히 하루를 86400초로 계산하여 순차적으로 증가시킨 것입니다.   



```python
from datetime import date

value = 1567345678

timestamp = date.fromtimestamp(value)
print("timestamp =", 1567345678)
print("Date =", timestamp)

# 결과
# timestamp = 1567345678
# Date = 2019-09-01

print( today.month )

print( today.hour )
print( today.minute )
```

## 🟢 DateTime 클래스를 통한 요일 알아내기

DateTime객체에는 weekday()함수를 제공하는데 이 함수는 요일에 대한 정보를 반환합니다
월요일:0, 화요일:1, 수요일:2, 목요일:3, 금요일:4, 토요일:5 일요일:6



```python
import datetime

# today = datetime.datetime.now()
today = datetime.date.today()
# ----------------------------------
print("요일 : ",today.weekday())
weekday = ["월요일", "화요일", "수요일", "목요일", "금요일", "토요일", "일요일"]
day = today.weekday()

print(f"{today}은 {weekday[day]} 입니다")

# print("{0}-{1}-{2} 는 {3} 입니다".format(today.year,        today.month, today.day, weekday[day]))

```

## 🟢 timedelta 날짜 또는 시간 사이의 차이 파악


```python
import datetime

# 오늘부터 3일 후 4시간 뒤
current_time = datetime.date.today()
after_3days = current_time + datetime.timedelta(days=3, hours=4)
print(f"오늘부터 3일 후 4시간 뒤는 {after_3days} 입니다.")


# 오늘부터 3일전하고 4시간 뒤
current_time = datetime.date.today()
before_3days = current_time - datetime.timedelta(days=3, hours=4)
print(f"오늘부터 3일전하고 4시간 뒤는 {before_3days} 입니다.")


# 오늘로부터 2주 전
current_time = datetime.date.today()
before_2weeks = current_time - datetime.timedelta(weeks=2)
print(f"오늘로부터 2주 전은 {before_2weeks} 입니다.")


```

    오늘부터 3일 후 4시간 뒤는 2025-07-07 입니다.
    오늘부터 3일전하고 4시간 뒤는 2025-07-01 입니다.
    오늘로부터 2주 전은 2025-06-20 입니다.

## 🟢 TimeZone(`pytz`) 각국의 시간 파악하기기


```python
import datetime
# 타임존 - 각 나라별 정보를 가져온다.
import pytz

print('나라별 name 파악하기')
print(pytz.all_timezones)
print()

# 현재 지역 시간 파악하기
format = '%Y-%m-%d %H:%M:%S'
local = datetime.datetime.now()
print( "현재 지역 시간 : ", local.strftime(format))


# 뉴욕 시간 파악하기
tz_ny = pytz.timezone('America/New_York')
local_ny = datetime.datetime.now(tz_ny)
print( "뉴욕 현재 시간 : ", local_ny.strftime(format))

# 런던 시간 파악하기
tz_london = pytz.timezone('Europe/London')
local_london = datetime.datetime.now(tz_london)
print( "런던 현재 시간 : ", local_london.strftime(format))


```
