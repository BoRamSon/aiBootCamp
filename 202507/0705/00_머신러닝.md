# 🟩 🧠 머신러닝(Machine Learning) 알아보기


<br>

## 🟢 개념

머신러닝은 컴퓨터가 명시적인 프로그래밍 없이 데이터를 이용해 스스로 학습하고, 새로운 데이터를 예측하거나 분류할 수 있게 하는 기술입니다.

머신러닝은 통계학과 최적화 이론, 확률론을 기반으로 합니다.

<br>

## 🟢 주요 분류

| 유형       | 설명                             | 예시                        |
| ---------- | -------------------------------- | --------------------------- |
| 지도학습   | 정답(Label)이 있는 데이터로 학습 | 이메일 스팸 분류, 가격 예측 |
| 비지도학습 | 정답이 없는 데이터에서 패턴 학습 | 고객 군집화, 이상 탐지      |
| 강화학습   | 보상을 통해 학습                 | 게임 AI, 로봇 제어          |


<br>

## 🟢 머신러닝 전체 과정 요약 (Mid-Level Summary)

### 1. 문제 정의 (Problem Definition)

- 해결하고자 하는 문제를 명확히 설정
- 목표: 예측인가? 분류인가? 군집인가?
- 출력값이 수치면 회귀, 범주면 분류, 레이블이 없으면 비지도학습

### 2. 데이터 수집 (Data Collection)

- 학습에 필요한 데이터를 확보
- 방법: 웹 크롤링, API, DB, 센서, 공개 데이터셋 등
- 가능한 다양한 샘플 확보 → 일반화 성능 향상

### 3. 데이터 전처리 (Data Preprocessing)

- 모델이 학습 가능한 형태로 데이터 정리
- 작업 예시:
  - 결측값 처리 (삭제, 평균 대체 등)
  - 이상치 제거
  - 범주형 → 수치형 인코딩 (Label / One-hot)
  - 정규화, 표준화 (MinMax, Z-score)

### 4. 탐색적 데이터 분석 (EDA)

- 데이터의 분포, 관계, 패턴을 시각적으로 분석
- 주요 도구: Pandas, Matplotlib, Seaborn
- 목표: 데이터의 품질과 의미를 직관적으로 이해

### 5. 특성 선택 / 엔지니어링 (Feature Selection & Engineering)

- 의미 없는 특성 제거, 중요 특성 선택
- 필요시 새로운 변수 생성 (예: 날짜 → 요일, 계절 등)
- 차원 축소(PCA)나 자동 특성 추출(딥러닝)도 포함 가능

### 6. 모델 선택 및 학습 (Model Selection & Training)

- 문제 유형에 맞는 알고리즘 선택:
  - 회귀: Linear Regression, SVR, XGBoost
  - 분류: Random Forest, SVM, CNN
  - 군집: KMeans, DBSCAN
- 학습 데이터로 모델을 훈련 (`model.fit(X_train, y_train)`)

### 7. 모델 평가 (Model Evaluation)

- 검증 데이터로 모델 성능 측정
- 주요 지표:
  - 회귀: MSE, RMSE, MAE, R²
  - 분류: Accuracy, Precision, Recall, F1-score, ROC-AUC
- 교차검증(Cross-validation)으로 신뢰도 향상

### 8. 하이퍼파라미터 튜닝 (Hyperparameter Tuning)

- 모델의 설정값을 자동/수동으로 최적화
- 기법:
  - GridSearchCV (모든 조합 시도)
  - RandomizedSearchCV (랜덤 시도)
  - Optuna, Bayesian Optimization

### 9. 테스트 및 배포 (Testing & Deployment)

- 최종 테스트 데이터로 검증 (모델의 진짜 성능 확인)
- API 서버 배포 (Flask, FastAPI, Django 등)
- Docker, AWS, GCP, CI/CD 등을 통해 실전 환경 적용

### 10. 모니터링 및 재학습 (Monitoring & Retraining)

- 실제 사용 시 성능 추적, 예측 오류 확인
- 데이터 드리프트 발생 시 재학습 필요
- MLOps 도구 (MLflow, DVC 등)로 자동화 가능

## 🟢 일반화 (Generalization)

- 모델이 **훈련 데이터뿐만 아니라 새로운 데이터에도 잘 작동**하는 능력.
- 머신러닝의 핵심 목표.
- 훈련 성능과 테스트 성능이 **모두 높음**.

## ❌ 과대적합 (Overfitting)

- 모델이 **훈련 데이터에 너무 맞춰져서**, 노이즈까지 학습함.
- 훈련 데이터 성능은 높지만, 테스트 데이터 성능은 낮음.
- 복잡한 모델, 데이터가 적거나 노이즈가 많을 때 발생.

### 🔎 특징

- 훈련 정확도: 매우 높음
- 테스트 정확도: 낮음
- 모델 복잡도: 너무 높음

<br>

## ❌ 과소적합 (Underfitting)

- 모델이 **너무 단순하거나, 학습이 부족해서** 기본적인 패턴도 못 잡음.
- 훈련/테스트 성능 모두 낮음.

### 🔎 특징

- 훈련 정확도: 낮음
- 테스트 정확도: 낮음
- 모델 복잡도: 너무 낮음

<br>

## 🎯 세 가지 비교표

| 구분     | 훈련 성능 | 테스트 성능 | 모델 복잡도 | 설명                        |
| -------- | --------- | ----------- | ----------- | --------------------------- |
| 일반화   | 높음      | 높음        | 적절        | 훈련/테스트 모두 잘 예측    |
| 과대적합 | 매우 높음 | 낮음        | 너무 높음   | 암기 위주 학습              |
| 과소적합 | 낮음      | 낮음        | 너무 낮음   | 학습 부족, 너무 단순한 모델 |

<br>

## ✅ 과대적합 방지 방법

| 방법           | 설명                                    |
| -------------- | --------------------------------------- |
| 데이터 수집    | 더 많은 데이터로 다양성 확보            |
| 특징 선택      | 불필요한 피처 제거                      |
| 모델 단순화    | 복잡도를 낮춰서 일반화 능력 향상        |
| 정규화 (L1/L2) | 가중치가 너무 커지지 않도록 제한        |
| Dropout        | 신경망 일부를 무작위로 끄며 학습        |
| Early Stopping | 검증 성능이 떨어지기 시작하면 학습 중단 |
